# Top Model Zimbabwe

# MASTER CREATIVE + DEVELOPMENT PROMPT

You are an elite creative director, award-winning digital art director, luxury fashion web designer, motion designer, UX strategist, and senior frontend engineer.

Your task is to design and build an **exceptional, immersive, award-winning modeling agency website**.

Do NOT create a generic modeling-agency template.

Do NOT make it look like a SaaS website, dashboard, startup landing page, or a typical AI-generated website.

The final result should feel like a combination of:

* a luxury fashion editorial

* a high-end fashion magazine

* an international modeling agency

* an experimental digital art experience

* an award-winning Awwwards/FWA-style website

* a cinematic fashion film

* a premium luxury brand

Think **fashion house + art installation + interactive portfolio**, rather than "business website."

## IMPORTANT CREATIVE RULE

Do not allow the visual language of Google AI Studio, Gemini, or other AI interfaces to influence the design.

The website should have its own completely independent visual identity.

Push the design beyond conventional web-design patterns.

If there is a choice between a safe, familiar implementation and a visually ambitious but usable implementation, choose the ambitious option.

---

# 1. CORE VISUAL DIRECTION

Create a sophisticated **glassy, liquid, colorful, cinematic world**.

The overall aesthetic should combine:

* translucent glass

* liquid gradients

* iridescent surfaces

* chrome

* subtle metallic reflections

* soft glow

* colorful atmospheric lighting

* deep blacks

* pure whites

* editorial typography

* photographic fashion imagery

* cinematic motion

* fluid distortion

* reflections

* depth

* layered transparency

Use multiple colors rather than relying on one brand color.

Potential color atmosphere:

* electric blue

* ultraviolet

* magenta

* hot pink

* cyan

* violet

* emerald

* coral

* champagne

* silver

* white

* near-black

However, avoid making it look childish, neon-gaming, or cyberpunk.

The colors should feel like **luxury lighting reflected through glass**.

Imagine colored light passing through a luxury fashion showroom.

---

# 2. THE BACKGROUND MUST FEEL ALIVE

Do not use a static background.

Create a fluid, continuously evolving background environment.

The background should behave almost like:

* liquid silk

* colored smoke

* oil floating on water

* glass reflections

* slowly moving aurora

* abstract light leaks

* flowing gradients

The background should subtly respond to:

### Mouse movement

The user's cursor should influence the environment.

For example:

* gradients should subtly follow the cursor

* light sources should shift

* background blobs should move with inertia

* glass reflections should react

* some elements should have slight magnetic movement

* the environment should feel physically connected to the pointer

Do NOT make the effect excessive or distracting.

It should feel expensive and sophisticated.

### Scrolling

The background should also react to scroll position.

Use:

* parallax

* depth changes

* color transitions

* gradient movement

* scale changes

* blur changes

* image displacement

* subtle perspective shifts

Different sections should feel like different atmospheric "rooms" within the same digital world.

---

# 3. HERO SECTION — MAKE THIS THE SHOWSTOPPER

The hero section must immediately communicate:

**FASHION. BEAUTY. EXCLUSIVITY. GLAMOUR. POWER. MOVEMENT.**

Do not create a standard hero with:

"Welcome to [Agency Name]"

followed by a button.

Instead, create an immersive cinematic opening.

Possible direction:

A full-screen fashion model image or fashion-film composition dominates the screen.

The model could appear to be:

* walking a runway

* turning toward the camera

* posing

* moving fabric

* walking through dramatic light

* emerging from darkness

* standing inside an architectural fashion environment

The model imagery should feel editorial rather than like a stock photograph.

If actual video assets are unavailable, architect the website so a video can easily be substituted later.

Use a high-quality fallback image with cinematic motion effects.

---

# 4. HERO IMAGE MOTION

The hero image should NOT simply sit still.

Create subtle depth and movement.

For example:

* foreground moves slightly differently from background

* image shifts with mouse movement

* model has subtle parallax

* background lighting moves independently

* image slowly zooms

* image slightly tilts based on cursor position

* scroll causes the model/image to move at a different speed than surrounding elements

Create a **2.5D cinematic effect**.

The user should feel that they are looking into a physical space rather than at a flat webpage.

Do this elegantly.

No cheap Ken Burns effect.

---

# 5. TYPOGRAPHY

Typography should feel like a luxury fashion publication.

Use a combination of:

### Primary display font

Elegant high-fashion serif or sophisticated editorial typeface.

### Secondary font

Minimalist modern sans-serif.

Use typography creatively.

Examples of behavior:

* oversized typography extending beyond the viewport

* extremely large editorial words

* thin uppercase labels

* vertical text

* typography partially hidden behind imagery

* text appearing through glass

* text moving subtly during scrolling

* typography becoming sharper/blurrier depending on depth

Do not overuse typography effects.

Luxury requires restraint.

---

# 6. NAVIGATION

Create an unusual but intuitive navigation system.

Consider:

A transparent floating glass navigation bar.

It should have:

* translucent glass

* backdrop blur

* subtle border

* soft reflection

* elegant typography

* smooth hover animations

Navigation could contain:

**HOME**

**MODELS**

**WOMEN**

**MEN**

**CREATIVE**

**ABOUT**

**CONTACT**

Include a sophisticated menu interaction on mobile.

Avoid a generic hamburger menu if you can create something more interesting without sacrificing usability.

---

# 7. HERO COPY

Keep the copy minimal.

Potential direction:

[AGENCY NAME]

MODEL MANAGEMENT

CREATIVE TALENT

FASHION / BEAUTY / CULTURE

Then a sophisticated CTA:

EXPLORE THE TALENT →

The typography and imagery should do most of the talking.

Do not fill the hero with paragraphs.

---

# 8. MODELS SECTION

This is one of the most important sections.

Do NOT use a boring grid of identical cards.

Create an editorial model discovery experience.

Potential layout:

Large asymmetric image compositions.

Each model could occupy different amounts of space.

For example:

Model 01 — huge portrait

Model 02 — narrow vertical image

Model 03 — large landscape

Model 04 — overlapping portrait

Model 05 — full-height editorial image

Allow images to overlap.

Use varying scales.

Use negative space.

Make the layout feel like a fashion magazine that has escaped the page.

---

# 9. MODEL INTERACTION

When the cursor moves over a model:

The model image should respond.

Possible effects:

* image slightly enlarges

* image shifts

* glass overlay appears

* model name reveals

* category appears

* cursor changes

* image becomes sharper

* surrounding elements subtly move away

* colored light appears behind the image

Create sophisticated hover choreography.

Do NOT use generic scale(1.05) hover effects everywhere.

---

# 10. MODEL DETAIL EXPERIENCE

When the user clicks a model, create an immersive transition.

Instead of immediately navigating to another boring page, animate the selected image into a larger editorial composition.

The model profile should contain:

* large photographs

* name

* measurements/details

* categories

* location

* portfolio

* campaign work

* social links

* booking/contact action

The transition should feel like entering a fashion editorial.

---

# 11. FULL-SCREEN EDITORIAL MOMENTS

Create several sections that deliberately break the normal website layout.

Examples:

### Editorial Statement

Huge text:

"BEAUTY

IN

MOTION."

The words should interact with the scrolling experience.

---

### Full-Screen Fashion Image

One enormous photograph fills the viewport.

As the user scrolls:

* image scales

* image shifts

* typography crosses over it

* lighting changes

* another image slowly emerges

---

### Horizontal Gallery

Introduce a horizontal scrolling fashion editorial within the vertical page.

The user continues scrolling vertically, but the content moves horizontally.

Use this sparingly and make it feel intentional.

---

# 12. GLASSMORPHISM

Use glass extensively, but intelligently.

Do not put every element inside a glass box.

Glass can be used for:

* navigation

* floating labels

* model information

* buttons

* filters

* contact panel

* floating UI elements

Use:

* backdrop blur

* transparency

* subtle borders

* internal highlights

* reflections

* shadows

* chromatic aberration where appropriate

The glass should feel physical.

---

# 13. CURSOR EXPERIENCE

Create a custom cursor.

Depending on context, it should transform.

Examples:

Normal:

small elegant dot/ring.

Over a model:

VIEW MODEL

Over an image:

EXPLORE

Over navigation:

subtle magnetic interaction.

Over draggable content:

DRAG

Make the cursor feel like part of the art direction.

Do not make it annoying.

Disable or simplify the custom cursor appropriately on touch devices.

---

# 14. SCROLL EXPERIENCE

Scrolling should feel cinematic.

Use:

* smooth scrolling

* inertia

* parallax

* image displacement

* reveal animations

* scale transitions

* opacity transitions

* typography movement

* depth layers

Elements should not all animate at once.

Create rhythm.

Some sections should move slowly.

Some should snap into focus.

Some should barely move.

Some should surprise the user.

The goal is to make scrolling feel like navigating through a fashion film.

---

# 15. INTRO / LOADING EXPERIENCE

Consider an elegant loading sequence.

For example:

A black screen.

A thin line appears.

Then:

[AGENCY NAME]

appears letter by letter.

A flash of an editorial image appears behind it.

The interface dissolves into the homepage.

Keep the loading experience short.

Never create a loading screen that frustrates users.

---

# 16. COLOR TRANSITIONS BETWEEN SECTIONS

Do not keep the entire site one color.

Let the atmosphere evolve.

Example:

Hero:

black + violet + champagne

Models:

white + pink + cyan

Editorial:

deep blue + electric purple

Creative:

coral + orange + magenta

About:

black + silver + emerald

Contact:

white + iridescent pastel

The transitions should be fluid rather than abrupt.

# 21. MICRO-INTERACTIONS

Add subtle details that reward exploration.

Examples:

* magnetic buttons

* image tilt

* text displacement

* liquid hover effects

* animated underlines

* glass reflections

* cursor interactions

* subtle image grain

* animated gradients

* floating particles

---

# 22. "OUTSIDE THE BOX" REQUIREMENT

I specifically want you to challenge conventional website design.

Explore ideas such as:

### Digital Fashion Film

Make the homepage feel like a continuous fashion film.

### Living Photography

Make photographs subtly move even though they are technically still images.

### Liquid Glass

Make glass elements appear to refract the environment behind them.

### Depth-Based Website

Treat the webpage as a 3D space rather than a stack of rectangles.

### Editorial Typography

Allow giant typography to become part of the architecture.

### Cursor as Navigation

Use the cursor as an interaction device rather than simply a pointer.

### Scroll as Camera Movement

Treat scrolling like moving a camera through a fashion set.

### Color as Storytelling

Let the color palette change as the user progresses through the agency's story.

Use these ideas selectively.

Do not implement everything simply because it is possible.

---

# 23. PERFORMANCE IS CRITICAL

Despite the visual ambition, the website must remain performant.

Use:

* lazy loading

* responsive images

* GPU-friendly transforms

* efficient animations

* requestAnimationFrame where appropriate

* IntersectionObserver

* optimized rendering

* reduced-motion support

* mobile-specific animation strategies

Avoid unnecessarily expensive effects.

Do not make the site beautiful only on a powerful desktop computer.

---

# 24. RESPONSIVE DESIGN

The desktop experience can be spectacular, but mobile must feel intentionally designed.

Do NOT simply shrink the desktop layout.

Create a mobile art direction.

On mobile:

* preserve the editorial feel

* simplify complex interactions

* maintain cinematic imagery

* use touch-friendly interactions

* remove expensive cursor effects

* maintain fluid backgrounds

* keep typography dramatic

* ensure navigation is excellent

---

# 25. ACCESSIBILITY

Include:

* semantic HTML

* keyboard navigation

* accessible buttons

* sufficient contrast

* alt text

* focus states

* reduced-motion support

* screen-reader-friendly navigation

Luxury design must not come at the expense of usability.

---

# 26. TECHNOLOGY

Build this as a modern production-quality frontend.

Prefer:

* React

* modern CSS

* Tailwind CSS where appropriate

* Framer Motion or another suitable animation system

* GSAP if required for sophisticated scroll choreography

* Three.js/WebGL only where it genuinely improves the experience

Do not add libraries merely for the sake of adding libraries.

Keep the architecture maintainable.

Separate:

* components

* data

* styling

* animations

* utilities

Model data should be easy to replace later.

---

Use realistic placeholder agency content.

12–16 models.

Each model should have:

* name

* gender/category

* age

* location

* height

* measurements

* specialties

* multiple images

Use believable fashion-industry names and information.

Do not use obviously fake placeholder text such as:

"Lorem ipsum."

The site should look convincing even before real content is inserted.

---

# 28. IMAGE STRATEGY

If image generation or remote image assets are unavailable, architect the website so real photography can easily be inserted later.

Use strong placeholder imagery rather than empty gray boxes.

Images should be treated as first-class design elements.

Use different crops and aspect ratios.

Avoid making every photograph the same size.

# 31. AVOID THESE COMMON AI-WEBSITE MISTAKES

Absolutely avoid:

* generic purple AI gradients

* generic SaaS cards

* excessive rounded rectangles

* predictable three-column layouts

* generic hero sections

* stock-template appearance

* excessive text

* repetitive animations

* random glassmorphism everywhere

* cheesy neon effects

* excessive shadows

* clutter

* meaningless 3D objects

* overcomplicated navigation

* inaccessible contrast

* animation for animation's sake

This is a **fashion house website**, not an AI demo.

---

# 32. THE "AWARDS JURY" TEST

Before considering the website complete, ask yourself:

"If this appeared in an Awwwards, CSS Design Awards, FWA, or similar showcase, would the visual experience be memorable?"

If the answer is no, keep iterating.

The website needs a recognizable creative idea.

It should have at least **3–5 moments that make a visitor stop and think:**

"How did they do that?"

---

# 33. IMPLEMENTATION BEHAVIOR

Do not merely describe the website.

Actually build the website.

Generate the complete frontend implementation.

Make all major interactions functional.

Do not leave major sections as static placeholders.

Do not give me a long explanation instead of building the interface.

Prioritize the actual visual result.

# 34. FINAL CREATIVE DIRECTION

The final experience should feel like:

You enter a dark fashion studio.

Colored light moves across the walls.

A model appears.

The background responds to your movement.

Glass elements float in space.

Typography moves slowly around the model.

You scroll.

The camera appears to move through the photograph.

The colors transform.

Another model emerges.

Editorial images overlap.

The agency's identity becomes increasingly clear.

By the time the visitor reaches CONTACT, it should feel as though they have experienced a **digital fashion campaign**, not browsed a normal website.

The website should communicate:

**EXCLUSIVITY.**

**BEAUTY.**

**MOVEMENT.**

**CONFIDENCE.**

**ART.**

**FASHION.**

**CULTURE.**

**GLAMOUR.**

Build something that feels **expensive, cinematic, experimental, and unforgettable.**

Do not play it safe.
